Sobre este site

Este site foi criado para a disciplina de Design de Interface onde serão colocadas em prática e postadas as atividades da disciplina. Cada página apresenta um trabalho diferente, utilizando das ferramentas HTML, CSS e JavaScript.

  • Trabalho 2: Prova online de múltipla escolha
  • Trabalho 3: Não solicitado

Sobre os Web Components

Web Components são elementos HTML customizados que encapsulam seu próprio HTML, CSS e JavaScript, podendo ser reutilizados em qualquer página do site.

A barra lateral com cabeçalho, navegação e rodapé é um web component definido uma única vez no arquivo componentes.js e reutilizado em todas as páginas com a tag <barra-lateral>.
